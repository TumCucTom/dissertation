# Dissertation

A minimal website that displays `Dissertation_template_main.pdf` using the browser’s built-in PDF viewer, with open and download links.

## Deploy on Vercel

Import this repository into Vercel and deploy from `main`. Use the repository root as the Root Directory. The included `vercel.json` configures static hosting with no framework or build step; no dependencies or environment variables are required.

To update the document, replace `Dissertation_template_main.pdf` while keeping its filename.
